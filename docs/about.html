About Roblox Alt Checker

Roblox Alt Checker is a small, independent website that answers one question: does this Roblox account look like somebody's main, or like a throwaway? It reads the public profile, scores what it finds, and shows you every point so you can disagree with it.

Who runs it

The site is built and run by one person, Deni (Ruslan Suvorov), trading as DENIXYZ in California. There is no company behind it beyond that, no investors, and no team of moderators. Support email, bug reports and refund requests all land in the same inbox and are answered by the same person. The contact page has the address and what to include.

Why it exists

Anyone who has run a Roblox group, a clan, a trading server or a mid-sized game has met the same problem. You ban someone, and a week later a brand-new account with a default avatar and a name ending in six digits is back doing the same thing. Or you are about to trade with a profile that was created yesterday and has one friend. Or a Discord server asks members to link a Roblox account, and half the links go to accounts with nothing on them.

The clues that something is off are all public. Roblox shows an account's join date, friend count, badges, groups, favorites, inventory (unless hidden) and avatar to anyone who opens the profile. Experienced moderators check those things by hand and form a judgement in a minute or two. This site does the same checks in a few seconds and writes the reasoning down, so a newer moderator, or a busy one, gets the same picture an experienced one would.

How the score works

Every account starts at 35 out of 100. Each thing the checker finds on the profile moves the number up (more like an alt) or down (more like a main). An account created in the last week adds 30 points; one that is three or more years old takes 12 off. No friends adds 12; fifty or more friends takes 10 off. Owning limited items, earning game badges over many different days, publishing a place that people have visited, having changed username before: all of these pull the score down, because they take time, money or effort that nobody spends on a throwaway. The final number is clamped between 0 and 100 and sorted into four verdicts.

The full list of signals and their weights is on the checker page, and the guide on reading an alt score walks through the cases where the number is misleading. The source code is public on GitHub, so the scoring is not a secret: anyone can read exactly what is counted and how.

What it will not do

  • It cannot prove anything. The score is a hint built from public counts. A quiet new player and a ban-evading alt can look identical on day one. Treat a high score as a reason to look closer, never as a verdict.
  • It cannot tell you whose alt an account is. It has no access to IP addresses, email addresses, payment details or anything else Roblox keeps private. A deep check can point out friends with near-identical usernames, and that is as far as it goes.
  • It never asks for a Roblox login. You type the name of the account you want to look at. The site never asks for your password or your .ROBLOSECURITY cookie, and neither should any other tool; the guide on account safety explains why.
  • It does not build a database of Roblox users. Results are held in memory for about ten minutes so that repeat lookups are fast, then dropped. Nothing is kept about who looked up whom.

How it is funded

Looking an account up means making a dozen or so requests to Roblox, and Roblox limits how fast anyone can do that. To keep the free tier free and fair, guests get a few lookups a day, free accounts get more, and those tiers show ads. Pro is a paid subscription that removes the ads, raises the daily limit and adds bulk checks. Every plan gets the same score from the same checks; paying does not buy a different answer. Payments go through Stripe and the refund policy is deliberately generous, because a tool like this should be easy to try and easy to walk away from.

Corrections

The guides describe how Roblox accounts, badges, limiteds and moderation tools work. Roblox changes these things, and the guides are updated when they do. If you spot something out of date or simply wrong, say so through the contact page; a dated note is added to the guide when a correction is made.
