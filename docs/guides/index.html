Guides to Roblox alt accounts

Plain-language explanations of how Roblox accounts work and how to tell a main from a throwaway, written for group owners, game moderators, traders and anyone who has been asked "is that an alt?". Each guide stands on its own; none of them needs the checker.

The guides describe Roblox as it works today. Roblox changes its features from time to time, and when a guide is corrected a dated note is added to it. If something looks out of date, say so.
